# Multi-blocks samples

This sample behavior/resource pack contains 2 multi-blocks, one vertical and one horizontal.

For more details about multi-blocks see the tutorial page [Create a Multi-Block](https://learn.microsoft.com/en-us/minecraft/creator/documents/multi-blocks?view=minecraft-bedrock-stable).

## Using the multi-blocks samples

To import this addon into your game simply open `multi_block.mcaddon` file with your `Minecraft.Windows.exe` game. This will launch Minecraft Bedrock Edition and import the two packs.
Then create a world with the `Upcoming Creator Features` experiment enabled, then you may add the two packs to your world and play it.
